# Portfolio Website V2

A personal portfolio website built with React and Vite.

This website presents my projects, technical skills, contact information, and downloadable CV in a clean and responsive layout.

## Features

- Responsive portfolio layout
- About section
- Featured project section
- Project cards with GitHub links
- Skills section
- Resume / CV download button
- Contact section
- Dark mode toggle
- Footer

## Technologies Used

- React
- Vite
- JavaScript
- CSS
- Git
- GitHub

## Projects Included

- Smart Home IoT System
- To-Do List WPF Desktop App
- Boxing Winner Prediction ML
- XDrive Website
- Personal Portfolio Website
